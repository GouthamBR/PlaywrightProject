🎭 Playwright + Pytest Automation Framework (Python)

This repository contains an end-to-end UI automation testing framework built using Playwright with Pytest in Python.
It is designed to be scalable, maintainable, and easy to execute across different environments and browsers.

📌 Tech Stack

Language: Python

Test Framework: Pytest

Automation Tool: Playwright

Design Pattern: Page Object Model (POM)

Reporting: Pytest HTML Report

Browser Support: Chromium, Firefox, WebKit

.
├── tests/                  # Test cases
│   ├── test_login.py
│   └── test_dashboard.py
│
├── pages/                  # Page Object classes
│   ├── login_page.py
│   └── dashboard_page.py
│
├── utils/                  # Utility/helper functions
│
├── reports/                # Test execution reports
│   └── report.html
│
├── pytest.ini               # Pytest configuration
└── README.md                # Project documentation

🧪 Key Features

✅ Page Object Model for maintainability

✅ Cross-browser testing

✅ Headed & headless execution

✅ HTML test reports

✅ Easy configuration via pytest.ini
